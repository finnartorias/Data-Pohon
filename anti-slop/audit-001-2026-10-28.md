# Anti-Slop Audit Report #001

Tanggal: 28 Oktober 2026  
Proyek: Sistem Manajemen & Monitoring Karbon Pohon Berbasis QR Code  
Status: Menunggu Persetujuan Pengguna

---

## Daftar Temuan (Numbered Findings)

1. **[R-23] [HIGH]** Placeholder foto eksternal dari Unsplash di-hardcode sebagai fallback spesies pohon pada `Tree::getFotoUrlAttribute()`.
   - *Alasan*: Aturan R-23 mewajibkan konfirmasi aset visual; lebih baik menggunakan ilustrasi siluet botani lokal atau placeholder netral berbasis SVG internal jika foto asli belum diunggah.

2. **[R-27] [HIGH]** Penanganan status kosong (empty state) saat hasil pencarian query pohon tidak ditemukan pada `resources/views/trees/index.blade.php`.
   - *Alasan*: Pesan saat ini bersifat umum ("Belum ada data pohon yang ditambahkan") alih-alih menginformasikan bahwa kata kunci pencarian tidak cocok dengan pohon manapun disertai tombol reset.

3. **[R-12] [MEDIUM]** Ikon avatar default pada navigation bar header admin menggunakan inisial statis tanpa sinkronisasi inisial akun admin yang sedang login.
   - *Alasan*: Avatar harus mencerminkan identitas pengguna asli secara dinamis (`auth()->user()->name`).

4. **[R-31] [LOW]** File template bawaan framework `resources/views/welcome.blade.php` masih ada di dalam direktori views meskipun rute `/` dialihkan langsung ke dashboard/index pohon.
   - *Alasan*: Menghapus file view template bawaan yang tidak terpakai menjaga kebersihan struktur repositori dari sisa template generik.

---

*Catatan: Sesuai aturan Anti-Slop Mode 2 (AFTER), silakan pilih nomor temuan di atas (misal: "perbaiki 1 dan 2") yang ingin dieksekusi. Bagian yang tidak disebutkan tidak akan diubah.*
